## Task 1：プッシュ通知プレビューの単語境界トランケート（目標：20分）

### 問題文
Androidアプリのプッシュ通知バナーに表示するメッセージ文字列 `message` と、バナーに表示可能な最大文字数 `K` が与えられます。
以下のルールに従って、通知プレビュー文字列を生成する関数 `solution(message: String, K: Int): String` を実装してください。

1. `message` は英字と単一の半角スペース `' '` のみで構成され、先頭や末尾にスペースはなく、連続するスペースも含まれません。
2. もし `message` 全体の長さが `K` 文字以下であれば、省略記号 `"..."` を付けずに `message` をそのまま返します。
3. `message` の長さが `K` を超える場合は、単語の途中で切れないように先頭から単語をいくつか選び、末尾に `" ..."`（半角スペース1つ＋ドット3つ、計4文字）を付与して、**全体の文字数が `K` 以下で最も長くなる文字列**を返します。
4. もし先頭の1単語すら `" ..."` と合わせて `K` 文字以内に収まらない場合（または `K < 4` の場合）は、`"... "` のスペースを除いた `"..."` のみを返します（ただし `K < 3` の場合は空文字列 `""` を返します）。

### 入出力例
- **例1**: `message = "And now here is my secret"`, `K = 15`
  - `"And now ..."`（11文字）を返す。（`"And now here ..."` は16文字となり `K = 15` を超えるため不可）
- **例2**: `message = "There is an animal with four legs"`, `K = 15`
  - `"There is ..."`（12文字）を返す。
- **例3**: `message = "super dog"`, `K = 4`
  - `"..."` を返す。（`"super ..."` は9文字で収まらないため）
- **例4**: `message = "how are you"`, `K = 20`
  - `"how are you"`（11文字）をそのまま返す。

### 制約
- `message` の長さ $N$ は $1 \le N \le 500$
- $K$ は $1 \le K \le 500$ の整数

### 関数シグネチャ

ネットワーク復帰時に、これらのイベントを**発生順序を保ったまま**最大 `maxBatches` 回のHTTPリクエスト（連続する部分配列のバッチ）に分割してサーバーへ送信します。

各バッチの送信コストは、以下の式で定義されます：
$$\text{バッチの負荷スコア} = (\text{バッチ内のイベントのデータサイズ合計}) + \text{headerOverhead} \times (\text{バッチ内のイベント個数})$$
（※ ただしバッチが空の場合はスコア 0）

通信タイムアウトを防ぐため、`maxBatches` 個以内のバッチに分割したときの **「最も負荷スコアが大きいバッチのスコア（最大バッチ負荷）」を最小化** したいです。達成可能な最小の「最大バッチ負荷スコア」を返す関数 `solution(maxBatches: Int, headerOverhead: Int, payloadSizes: IntArray): Long` を実装してください。
