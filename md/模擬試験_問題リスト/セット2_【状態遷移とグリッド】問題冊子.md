## Task 1：リッチテキストエディタのUndo/Redo＆数値スタック操作（目標：25分）

### 問題文
ノートの編集履歴を管理する数値スタックマシンがあります。空白区切りのコマンド文字列 `S` が与えられるので、先頭から順にコマンドを実行し、**すべてのコマンド実行後にスタックの先頭（一番上）にある整数**を返す関数 `solution(S: String): Int` を実装してください。ただし、途中でエラーが発生した場合や、最後にスタックが空の場合は `-1` を返します。

各トークンは以下のいずれかです（Codility名作「WordMachine」拡張）：
1. **非負整数 `"X"`**（$0 \le X \le 1,048,575 = 2^{20} - 1$）：スタックに整数 $X$ をプッシュする。
2. **`"POP"`**：スタックの一番上の要素を取り除く（スタックが空ならエラー）。
3. **`"DUP"`**：スタックの一番上の要素を複製してプッシュする（スタックが空ならエラー）。
4. **`"+"`**：スタックの上から2つの要素をポップし、その和をプッシュする（要素が2つ未満、または和が $1,048,575$ を超えるオーバーフロー時はエラー）。
5. **`"-"`**：スタックの一番上の要素（1個目）から、その次の要素（2個目）を引いた値（$\text{top}_1 - \text{top}_2$）をプッシュする（要素が2つ未満、または結果が負になるアンダーフロー時はエラー）。

### 入出力例
- **例1**: `S = "4 5 6 - 7 +"`
  - `4` -> `[4]`
  - `5` -> `[4, 5]`
  - `6` -> `[4, 5, 6]`
  - `-` -> $6 - 5 = 1$ -> `[4, 1]`
  - `7` -> `[4, 1, 7]`
  - `+` -> $7 + 1 = 8$ -> `[4, 8]`
  - 最終的な先頭要素 `8` を返す。
- **例2**: `S = "13 DUP 4 POP 5 DUP + DUP + -"` -> `7` を返す。
- **例3**: `S = "5 6 + -"` -> `-` の時点で要素が1つしかないため `-1` を返す。
- **例4**: `S = "3 DUP 5 - -"` -> $5 - 3 = 2$ の後、$2 - 3 = -1 < 0$ となるため `-1` を返す。

### 制約
- `S` の長さは $0 \le \text{length} \le 50,000$
- **要求計算量**: Time $O(N)$、Space $O(N)$
